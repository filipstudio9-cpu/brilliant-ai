# Brilliant AI

**Умный ИИ-ассистент для Android. Бесплатно, без подписок.**

Brilliant AI — это чат-бот на основе модели Ruby-1. Помогает писать тексты, решать задачи, генерировать идеи и разбираться в коде.

[Скачать в RuStore](https://www.rustore.ru/catalog/app/com.brilliantai.app)

---

## Что умеет

- **Тексты** — посты, статьи, письма, поздравления
- **Задачи** — учёба, логика, математика
- **Идеи** — названия, сценарии, планы
- **Код** — пишет и объясняет на разных языках
- **Вопросы** — отвечает на любые темы

## Особенности

- Полностью бесплатно, без подписок и скрытых платежей
- История чатов хранится локально на устройстве
- Тёмная и светлая темы
- Работает на Android 7.0+
